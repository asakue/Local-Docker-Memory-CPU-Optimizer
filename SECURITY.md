# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in dockertrim, please do not open a public issue.
Instead, report it via private vulnerability reporting on GitHub or contact the maintainer directly.
We appreciate your efforts to responsibly disclose findings.
